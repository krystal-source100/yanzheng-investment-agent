# 约120秒演示脚本

优先在真实金融与LLM联调通过后录制。若只能使用演示模式，开头必须说“以下为构造数据流程演示”，不能冒充真实数据成果。题目14视频为可选。

0—20秒：这是研证，面向已有初步投资判断、但缺少数据验证的个人投资者。用户从一个判断出发，对照支持证据、反例与信息缺口。

20—45秒：输入“利润增长很快，所以盈利质量也在改善”。展示模型拆解，区分增长和现金流问题，用户修改路径、确认报告期。演示模式说明这里是规则拆解，未调用LLM。

45—75秒：执行检查，展示真实取数结果或明确标注的构造样例。说明利润率方向与现金流方向可能不同，支持和反例共存，不强行输出投资结论。

75—95秒：展开一项证据，查看源字段、原值、单位、期间、请求ID与计算公式。切换缺失或接口失败示例，说明不静默补数。

95—115秒：记录自己的判断修正，保存研究。从研究记录恢复，导出证据，继续检查回款效率。

115—130秒：说明价值与限制。LLM理解问题与组织路径；金融工具取数；程序计算；用户复核。首版不验证未来股价或经营原因。展示实际完成的测试结果及尚未验证事项。
