# 研证：投资判断验证助手

同花顺题目14：AI Native投资产品创新。

用户已有初步判断，却缺少数据验证。研证把判断拆成可检查的问题，查询真实财务指标，展示支持证据、相反证据与信息缺口，帮助用户修正判断。

## 快速运行

Node.js >=22.13，使用仓库中的 pnpm-lock.yaml：

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm dev
```

托管构建沿用 Vinext / Cloudflare Workers 和 Sites starter。不要移除 vite.config.ts 中 sites() 集成。构建：`corepack pnpm build`。部署项目身份保存在 `.openai/hosting.json`。

## 两种运行模式

- **演示模式**：固定虚构公司的指标，规则拆解，不调用金融接口或LLM。支持正反证据、数据缺失、接口失败、指标无变化四个场景。页面、证据和导出文件都保留演示标记。
- **真实模式**：需要金融和模型凭据。连接设置可在页面会话内填写凭据；刷新后清除。也可在服务端安全配置 `.env.example` 中的四个变量。密钥不写入仓库、研究记录或导出文件。没有配置或接口失败不自动回退演示模式。

模型支持HTTPS Chat Completions兼容接口，地址根路径拼接 `/chat/completions`。将 `LLM_BASE_URL` 设置为服务商的实际根路径；`LLM_MODEL` 必须是账号可调用的模型。托管运行时用安全环境变量配置，禁止在源码和hosting.json内填写真实密钥。

## 用户流程

输入判断 → 确认检查问题与报告期 → 查询两期数据 → 对照正反证据 → 查看原始字段 → 复核、追问、保存或导出。

用户可修改三个检查路径：增长与盈利、利润与现金、回款效率。先从2020年以后的非金融A股开始，仅比较相邻年份同类报告。手动输入明确的带交易所代码，首版没有名称搜索、行业自动识别或自动最新报告检测。

## 数据来源与口径

仅使用扶摇：`GET /api/a-share/financials/indicators?thscode=...&report=...`。

官方文档：https://fuyao.aicubes.cn/docs/api-reference/financial-indicators/

支持营业收入与归母净利润同比增长率、销售毛利率和净利率、净利润现金含量、销售现金比率、应收账款周转率。同比增长率采用数据源字段；两期差值由程序计算。百分比指标差值为百分点，不是同比。应收周转率单位为次。净利润现金含量的单位与公式尚未通过实际权限接口核验，因此只保留原始源值展示，不假定百分比或设置绝对阈值。所有证据保留源字段、原值、请求ID、报告期、获取时间和原始响应。获取时间不等于公告发布时间。

缺失返回null，不当作零；业务code非0即失败，即使HTTP状态为200。拒绝标的或报告期回显不一致的响应。

## AI与程序边界

LLM只做自然语言意图映射与带证据的解释。检查计划被有限topic schema约束，可人工修改。后台依据白名单选择金融查询并计算，模型不能构造URL、改原始数据或执行买卖操作。

确定性程序校验期间、解析数值、计算差值和按方向组织证据。支持/相反方向不等于投资结论；完整性不等于数据真实度。LLM解释要求引用已有有效字段，不允许新数字、收益承诺或买卖建议；验证失败则保留数据并标注AI解释失败。这只能降低错误风险，不能保证解释完全正确。

真实模式判断文本与结构化结果会发送到用户指定的模型服务。不使用身份信息、KYC或真实持仓。研究记录保存到当前浏览器localStorage，最多30条，不跨设备同步；可导出与删除。

## 实际字段适配修正

文档字段名与用户实际响应有差异：营收增长映射calculate_operating_income_yoy_growth_ratio；归母增长映射calculate_parent_holder_net_profit_yoy_growth_ratio，明确不以总净利润字段替代归母口径。导出保留统一指标ID及两期实际源字段。多种同义字段冲突则不自动择一。实际指标接口未返回现金流增速，现金路径使用已返回的销售现金比率作为补充，但仍明确没有现金流原始金额与增速。归母增长不能与现金含量分母未经核验的利润口径直接对应。

## 评审快速体验

开发服务启动后打开终端显示的本地地址；默认演示模式无需Key。点击示例→拆解判断→确认并检查→展开证据→保存研究→导出证据，可体验主链路。演示中的公司、数字与拆解均明确标注为构造/规则，不冒充真实AI结果。

真实模式：连接设置→填写金融Key及模型Base URL、模型名、模型Key→测试连接→使用此模式→输入带交易所代码及相邻年份同类报告期→执行验证。正式评审如不提供自有Key，需要候选人通过服务端安全环境变量提前配置评审用凭据；不能把凭据写进README或源码。免费额度和账号权限由服务提供方决定。当前没有预存服务端凭据，因此真实模式需要会话配置。

## 环境变量说明

| 名称 | 用途 | 是否敏感 |
| --- | --- | --- |
| HITHINK_FINANCE_API_KEY | 扶摇金融数据凭据 | 是 |
| LLM_BASE_URL | HTTPS Chat Completions兼容服务根地址 | 否 |
| LLM_MODEL | 账号可调用的模型ID | 否 |
| LLM_API_KEY | 模型调用凭据 | 是 |

`.env.example`只包含变量名称和空值，不会自动加载为真实配置。托管运行时通过安全环境变量设置；本地试用优先使用会话连接设置。刷新会清除会话凭据。
